## 1. Test Environment Classification & Disclaimers

To guarantee strict separation between mocked tests, simulated concurrency harnesses, real PostgreSQL integration tests, and browser-based E2E tests, every scenario in this matrix is assigned an explicit **Test Type** and **Required Environment** code:

| Environment Code | Test Type Classification | Backing Persistence / Infrastructure | Safety & Disclosure Rule |
| :--- | :--- | :--- | :--- |
| **`ENV-UNIT`** | `UNIT_MOCK` | Pure function / Zod schema / mocked dependencies (`DATABASE_URL=""`). | Never reported as database or persistence verification. |
| **`ENV-MEM-INT`** | `REPO_INTEGRATION_MEM` / `API_ROUTE_INTEGRATION` | Next.js route handlers & domain services running against `NODE_ENV=test` isolated in-memory repositories (`__gh_mem_*`). | Verifies business logic, RBAC, IDOR guards, and HTTP status codes. Never claimed as real PostgreSQL verification. |
| **`ENV-SIM-PG`** | `SIMULATED_PG_CONCURRENCY` | In-memory simulated multi-connection PostgreSQL harness modelling `SELECT ... FOR UPDATE`, `23505` unique constraints, and rollback. | Verifies application SQL query structure and lock-ordering logic; does not replace `ENV-PG-ISOLATED`. |
| **`ENV-PG-ISOLATED`** | `REAL_POSTGRES_ISOLATED` | Dedicated, disposable PostgreSQL instance or isolated Neon test branch (`TEST_DATABASE_URL` + `ALLOW_DISPOSABLE_DB_TESTS=1`). | **Mandatory for true DB concurrency, constraint, and multi-process rate-limit sign-off.** Strictly blocked from connecting to `greathomes-production` primary compute. |
| **`ENV-R2-SANDBOX`** | `STORAGE_INTEGRATION` | Isolated test R2 bucket or mocked S3 client verifier (`STORAGE_PROVIDER=s3`). | Never writes test objects to or deletes objects from production `greathomes-media` bucket. |
| **`ENV-BROWSER-E2E`** | `BROWSER_E2E` / `MANUAL_RESPONSIVE_UI` | Headless Playwright browser or manual viewport verification (`360x800`, `390x844`, `768x1024`, `1440x900`) against isolated dev server. | Verifies DOM rendering, wizard navigation, scroll reset, and responsive layout. |

> **Absolute Production Safety Mandate:** Zero tests in this matrix may execute against the production Neon compute endpoint (`greathomes-production`) or production Cloudflare R2 storage. If `ENV-PG-ISOLATED` or `ENV-R2-SANDBOX` is unavailable during Step 3 execution, those specific scenarios must be recorded as `BLOCKED`—never substituted with mocks and reported as passed live tests.
